# Gov50: Data Science for the Social Sciences <a href='https://gov50.mattblackwell.org/'><img src='files/img/gov50-icon-512.png' align="right" height="139" /></a>

This repo houses the Quarto sources for an updated version of the GOV 50 website which is built directly off of [Matt Blackwell's](https://mattblackwell.org/) [GOV 50 course from Fall 2023](https://github.com/mattblackwell/gov50-f23.github.io).

## How to build this site

1. Install the most recent version of [R](https://cran.r-project.org/) and [RStudio](https://docs.posit.co/ide/user/#rstudio-ide-oss-downloads)
2. Open `site.Rproj` as an RStudio Project.
3. Edit files as needed and hit the "Render" button to preview the changes locally. 
4. Commit changes and push them to GitHub. GitHub Actions will build the site and deploy it to [https://gov50-f26.github.io](https://gov50-f26.github.io).
